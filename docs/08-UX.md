# Goldweaver – Bedienkonzept (UX-Review)

Stand: 08.11.2026. Ergebnis der Prüfung „Sind die geplanten Anzeigen einfach, kompakt und sofort verständlich?" gegen die meistgenutzten Addons derselben Kategorie. Dieses Dokument ist für WP1.7 (UI-Kit), WP1.3 (Tooltip), WP1.5 (Post), WP3.x (AH) und WP4.x (HUD/Dashboard) verbindlich und ersetzt die UI-Beschreibungen in `01-KONZEPT.md` Abschnitt 4.2, wo sie abweichen.

## 1. Was die großen Addons richtig machen

## 3. Zehn Bedienregeln

1. **Tooltip zuerst, Fenster zuletzt.** Alles, was sich pro Item sagen lässt, steht im Tooltip. Ein Fenster nur für Listen.
2. **Eine Zeile, eine Zahl, eine Empfehlung.** `Goldweaver: Entzaubern ≈ 1g 20s (AH 95s, Händler 12s)`. Begründung erst mit Shift.
3. **Im Blizzard-Fenster bleiben.** Briefkasten, Berufefenster, Auktionshaus und Taschen bekommen Knöpfe oder eine Seitenleiste. Kein eigenes Fenster, solange ein passendes Blizzard-Fenster offen ist.
4. **Ein Goldweaver-Fenster (`/gw`), vier Tabs:** Heute · Berufe · Charaktere · Einstellungen. Nie mehr.
5. **Knopf = Verb + Objekt + Zahl.** `An Nerion senden (17 Items, 5g 10s)`, `Entzaubern: Grüne Robe (≈1g 20s)`, `Herstellen: Leinenbolzen ×10 (+85s)`.
6. **Jede Zahl trägt Quelle und Alter.** `1g 20s · Auctionator, 2 h` oder `1g 20s · selbst gesehen, 3 Tage`. Ohne Quelle keine Zahl. Unbestätigte Daten (Favor, Entzaubertabelle) zeigen `~`.
7. **Null Einrichtung.** Erstlauf fragt nur die Rolle. Höchstens zehn Einstellungen insgesamt, alle mit funktionierendem Default. Keine Gruppen, keine Operationen, kein Desktop-Programm.
8. **Spielfarben, kein eigenes Farbsystem.** Itemqualität wie im Spiel, Gewinn grün, Verlust rot, Hinweis gold (eine Akzentfarbe). Keine Icons, die man lernen muss; Text statt Symbol.
9. **Progressive Tiefe.** Shift im Tooltip zeigt alle Optionen; Rechtsklick auf eine Empfehlung zeigt die Rechnung. Wer es nicht will, sieht es nie.
10. **Deutsch und Englisch gleichwertig.** Spielbegriffe exakt wie im Client (Entzaubern, Posten, Einzahlung), damit niemand übersetzen muss.

## 4. Die sieben Ansichten (Mockups)

### 4.1 Tooltip (jedes Item, überall)
```
Leinenstoff                                     ← Blizzard-Tooltip
Stoff · Stapel 20
Verkaufspreis: 13 Kupfer
────────────────────────────────────────────────
Goldweaver: Zum Twink schicken → Bolzen ≈ 1g 42s   ← eine Zeile, gold
  (Shift: AH roh 95s · Kiste 5g 00s~ · Händler 2s 60c)   ← nur mit Shift, grau
```
Regeln: Zeile 1 nennt die beste Aktion und ihren Wert; `~` markiert unbestätigte Daten; Shift zeigt alle Optionen in einer Zeile. Auf dem Verarbeiter steht statt „Zum Twink schicken" direkt „Bolzen herstellen".

### 4.2 Taschen-Markierung
```
┌────┐ ┌────┐ ┌────┐
│ ▲  │ │    │ │ ●  │     ▲ = zum Twink (gold)    ● = entzaubern (lila)
│ 20 │ │  3 │ │    │     kein Symbol = behalten/vendorn
└────┘ └────┘ └────┘
```
Ein Symbol in der Ecke, zwei Bedeutungen, abschaltbar. Funktioniert mit Blizzard-Taschen, Bagnon und Baganator (nur Overlay, kein eigenes Bag-Fenster).

### 4.3 Briefkasten (Blizzard-Fenster, Postal-Muster)
```
┌ Posteingang ──────────────────────────────── [Alles abholen] ┐
│ Verkauft: 12g 40s (6 Auktionen) · Einzahlung zurück: 1g 05s  │   ← eine Zeile nach dem Abholen
│ ...                                                           │
└───────────────────────────────────────────────────────────────┘
┌ Senden ───────────────────────────────────────────────────────┐
│ An: [Nerion            ▼]    ← Vorschlag aus Registry (Rolle Verarbeiter)
│ [An Nerion senden (12 Items, 4g 32s)]  [Nächste 12 →]         │   ← ein Klick = ein Brief
│ Enthält: Leinenstoff ×40, Grüne Robe, Wollstoff ×17 …         │
└───────────────────────────────────────────────────────────────┘
```
Der Knopf füllt die Anhänge und sendet in einem Klick (Hardware-Event). Bei mehr als zwölf Items erscheint „Nächste 12", wieder ein Klick. Keine Automatik.

│                                      ││ [Herstellen ×8]   [Fehlendes suchen]│
│                                      ││                                    │
│                                      ││ LOHNT SICH (nach 5 % AH-Cut)       │
│                                      ││ Leinenbeutel        +12s  ×∞       │
│                                      ││ Leinenbolzen        +4s   ×10      │
│                                      ││ Wollener Umhang     −8s            │

Drei Blöcke, drei Knöpfe. „Herstellen" ruft das Blizzard-Craft auf, „Fehlendes suchen" füllt die AH-Suche (kein Kauf). „Entzaubern" ist der Secure-Button, ein Klick pro Item. Dieselbe Leiste für jeden Beruf; bei Sammelberufen zeigt Block 1 „Nächste Zone" statt „Nächster Skill-up".

Höchstens drei Empfehlungen, jede anklickbar (führt zum Ort: Berufefenster, Kiste, Briefkasten). Tab „Berufe" ist der Berufs-Vergleich (eine Tabelle: Beruf · Skill · Kosten bis 300 · bester Craft). Tab „Charaktere" ist die Rollenliste. Tab „Einstellungen" hat maximal zehn Schalter.

### 4.8 Erstlauf-Karte (einmal pro Charakter)
```
┌ Goldweaver ─────────────────────────────────────────────┐
│ Was macht dieser Charakter?                              │
│ [Sammelt unterwegs]  [Verarbeitet & verkauft]  [Bank]    │
│ Später änderbar mit /gw role. Mehr ist nicht nötig.      │
└──────────────────────────────────────────────────────────┘
```
Eine Frage, ein Klick. Danach sind Tooltip, Taschen-Markierung und Briefkasten-Knopf aktiv.

## 5. Erlernbarkeit: wie Spieler wissen, was zu tun ist
- **Der Tooltip erklärt sich selbst:** Wer ein Item anschaut, sieht die Empfehlung. Kein Handbuch nötig.
- **Knöpfe erscheinen nur, wo sie wirken:** Briefkasten, Berufefenster, AH. Nichts muss gesucht werden.
- **`/gw` ohne Argument** zeigt vier Zeilen: Rolle setzen, Tooltip-Shift, wo die Knöpfe sind, Einstellungen. Nicht mehr.
- **CurseForge-Seite:** drei Screenshots (Tooltip, Briefkasten-Knopf, Seitenleiste) und ein Satz pro Screenshot. Keine Feature-Liste mit 30 Punkten.
- **Fehlerfall sichtbar:** Fehlt eine Preisquelle, sagt der Tooltip `Goldweaver: kein Preis bekannt · AH öffnen oder Auctionator installieren`.

## 6. Was wir bewusst nicht bauen
- Kein eigenes Taschen-, Post-, AH- oder Berufefenster.
- Keine Gruppen/Operationen, keine Desktop-App, keine Pflicht-Abhängigkeit.
- Keine Icon-Sprache, keine mehrfarbigen Statusleisten, keine Minimap-Menüs mit Untermenüs.
- Kein Dauer-Fenster außer der einen HUD-Zeile, und die ist standardmäßig aus.

## 7. Auswirkungen auf die Roadmap
- **WP1.7 UI-Kit** schrumpft auf: Tooltip-Zeile, Taschen-Overlay, Knopf-Vorlage „Verb + Objekt + Zahl", Seitenleisten-Container, ein Fenster mit vier Tabs, Erstlauf-Karte.
- **WP1.3 Advisor-Tooltip** ist die wichtigste Anzeige und wird zuerst gebaut; sie ist der Test, ob das Addon ohne Erklärung verstanden wird.
- **WP1.5 Post** wird als Knöpfe im Blizzard-Briefkasten umgesetzt.
- **WP3.x AH** im MVP nur Preisvorschlag im Verkaufen-Tab und Preis-Mitlesen; eigener Scan und Einkaufslisten nur ohne Auctionator.
- **WP4.2 Dashboard** entfällt zugunsten des Tabs „Heute" mit drei Empfehlungen.
- **Neu WP1.9 Onboarding:** Erstlauf-Karte, `/gw`-Kurzhilfe, drei Screenshots.
- **Abnahmetest für jede Ansicht:** eine Person, die das Addon nicht kennt, versteht in 30 Sekunden ohne Erklärung, was sie tun soll. Sonst wird vereinfacht.
